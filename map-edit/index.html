nesphp Map Editor (ドラクエ風の街)

ツール

左ドラッグ: 塗る / 置く
右クリック: タイルを拾う (スポイト)
Esc: 「選択 / 編集」に戻る
「選択」でオブジェクトをクリックすると右で編集

オブジェクト

選択ツールでオブジェクトをクリック
at ()

出力

「出力」→ town_map.php と town.data.bin を examples/ に保存して make build/town.nes。
日本語メッセージには BDF (chr-edit/misaki_bdf_2021-05-05/misaki_gothic.bdf) を先に読み込む。
勇者の開始位置は「勇者」ツールで置く。外周は通行不可のタイルにする (通行可: 床 / 草 / 橋)。
宝箱はマップに宝箱タイルを置き、さらに「宝箱」ツールでメッセージを付ける。
