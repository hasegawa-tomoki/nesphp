# map-edit — ドラクエ風の街のマップエディタ

`examples/town.php` (歩き回れる街) が読むマップ / NPC / 宝箱 / メッセージを編集して、
`examples/town_map.php` と `examples/town.data.bin` を出力する単体 HTML です
(`chr-edit` と同じ流儀。サーバー不要、`index.html` をブラウザで開くだけ)。

## 使い方

1. `map-edit/index.html` をブラウザで開く (ファイルをダブルクリックで OK)。
2. **font.chr を読む** → `chr/font.chr` (リポジトリ直下の `chr` フォルダ) を選ぶと実タイルで表示される。
   一度読めば localStorage に残る。読まなくても色付きの四角で編集はできる。
3. **BDF を読む** → `chr-edit/misaki_bdf_2021-05-05/misaki_gothic.bdf` を選ぶと日本語 (漢字込み) の
   メッセージが書ける。これも localStorage に残る。ASCII だけなら不要。
4. **JSON を読む** → `map-edit/town.json` でサンプルの街が開く。編集内容は localStorage に自動保存され、
   **JSON を保存** でファイルにも残せる。
5. 編集後 **town_map.php + data.bin を出力** → **php をダウンロード** と **data.bin をダウンロード** で
   2 ファイルを保存し、どちらも `examples/` に置く (ファイル名は `town_map.php` / `town.data.bin` のまま)。
6. `make build/town.nes` → `make run:town`。

コマンドラインでも同じものを作れる:

```
node map-edit/gen.js map-edit/town.json examples/town_map.php examples/town.data.bin \
     chr-edit/misaki_bdf_2021-05-05/misaki_gothic.bdf
```

## 編集操作

| 操作 | 内容 |
|---|---|
| 左ドラッグ | 選んだタイルを塗る / NPC・宝箱・勇者を置く |
| 右クリック | そのマスのタイルを拾う (スポイト) |
| Esc | 「選択 / 編集」ツールに戻る |
| 「選択 / 編集」ツールでオブジェクトをクリック | 右のパネルで NPC の種類、メッセージの編集、削除 (設定済みのセリフを解除するのもここの「削除」) |
| オブジェクトをドラッグ | NPC・セリフ・勇者を別のマスへ移動 (タイル以外のツールならどれでも可。勇者は「選択 / 編集」ツールで)。置けるマスは緑、ほかのオブジェクトがいるマスは赤の枠。宝箱タイルの上のセリフは宝箱タイルごと動き、元のマスはレンガ床になる |
| 矢印キー | 選択中のオブジェクトを 1 マス動かす (メッセージ欄に入力中は効かない) |
| 「勇者 (開始位置)」 | 開始位置を置く |
| 幅 / 高さ + サイズ変更 | マップサイズ変更 (最小 16×15、幅 ≤ 255、幅×高さ ≤ 4080) |

## 注意点

- **外周** (マップの一番外側の行と列) に通行可能なタイル (床 / 草 / 橋) があると出力を拒否する。
  エンジンが op 節約のため境界チェックを省いているため。木や壁で囲むこと。
- **セリフ (任意のマス)** ツールはタイルを変えずにメッセージだけを置く。目の前で A を押すとメッセージが
  出る (みかんの象や看板、宝箱などに)。通行は妨げない (タイルが通行不可なら入れないだけ)。
  **宝箱 (タイル + メッセージ)** は宝箱タイルを置いてセリフも付ける便利版。
  エディタ上ではメッセージ付きの宝箱の右上に小さな印が出る (黄 = メッセージあり、赤 = 未設定)。
- タイルの絵を `chr/make_town_tiles.php` で変えた後は、エディタで **font.chr を読む** をやり直す
  (読み込んだ CHR は localStorage に保存され、自動では更新されない)。
- **メッセージ** は最大 3 行 × 25 文字。ASCII は常駐フォント、それ以外の文字は BDF から字形を取り、
  メッセージごとにグリフスロット (60 個) に載る。1 つのメッセージ内の異なり文字が 60 を超えると `?` になる
  (警告が出る)。全角スペースは半角に置き換わる。
- **カウンター越し**の会話: 目の前がカウンターで誰もいなければ、その向こうの人に話しかけられる。
  店主や宿屋の主人はカウンターの奥に置く。
- 通行可能なタイルは床 / 草 / 橋。扉は A で開けると床になる。
- NPC は何体置いてもよいが、**同時に画面内に表示できるのは 15 体まで** (sprite 64 枚の制限。勇者が 4 枚、NPC 1 体 4 枚)。
  1 走査線に 5 体以上並ぶとちらつく (ファミコンの仕様。消える代わりに毎フレーム順番を回している)。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `editor.js` | エディタ本体 |
| `export.js` | JSON → `town_map.php` / `town.data.bin` の変換と BDF パーサ (ブラウザと node 共用) |
| `gen.js` | node 用の変換コマンド |
| `town.json` | サンプルの街 |

データ形式 (bank 3 / ROM bank 2 の配置、グリフの扱い) は [spec/14-map-scroll.md](../spec/14-map-scroll.md) を参照。
